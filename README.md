# Web-Portfolio: Dennis Gorski

Quellcode meiner persönlichen Entwickler-Webseite. Das Projekt dient als digitale Visitenkarte und zentraler Ankerpunkt für meine Code-Projekte, IT-Zertifizierungen und meinen beruflichen Werdegang.

## 🛠 Tech Stack
* **Struktur:** HTML5 (semantisch)
* **Design:** CSS3 (Vanilla, Flexbox, responsiv)
* **Deployment:** Netlify (CI/CD via GitHub)
* **Domain & DNS:** Spaceship

## 📁 Projektstruktur
* `index.html` - Startseite & Kurzprofil
* `about.html` - Detaillierter Lebenslauf (Timeline)
* `projekte.html` - Übersicht der IT-Projekte, Repositories und Zertifikate
* `kontakt.html` - Kontaktformular
* `/Stylesheets/` - Ausgelagerte CSS-Formatierung
* `/Zertifikate/` - PDF-Nachweise (Cisco, IBM, IU Akademie)

## 💡 Hintergrund
Dieses Portfolio wurde im Rahmen meiner Umschulung zum Fachinformatiker für Anwendungsentwicklung strukturiert. Der Fokus bei der Umsetzung lag auf schnellen Ladezeiten, schlankem Code ohne überladene Frameworks und einer sauberen Trennung von Struktur und Design.
